# UI/UX Design Rules

These rules must be followed whenever creating,
modifying, or improving any frontend interface.

## Core Principle

Create unique, professional, product-focused designs.
Avoid generic AI-generated aesthetics and template-like
interfaces.

## Design Requirements

- Establish a distinctive visual identity.
- Avoid excessive gradients, glassmorphism, shadows,
  glowing effects, and decorative elements.
- Avoid repetitive card-based layouts and generic grids.
- Maintain consistent typography, spacing, colors,
  and component styles.
- Use meaningful layouts based on actual user needs.
- Avoid unnecessary icons, badges, animations, and containers.
- Ensure responsive designs across all screen sizes.
- Prioritize accessibility and usability.
- Use meaningful content and functional interactions.
- Include proper loading, empty, and error states.

## Implementation Requirements

- Use semantic HTML.
- Write clean, maintainable CSS.
- Create reusable components where appropriate.
- Follow the existing project's technology stack.
- Do not introduce unnecessary dependencies.

## Design Decision Rule

Before implementing a UI, understand the product,
target audience, user workflow, and purpose of the page.

Every visual element must have a clear purpose.
Prioritize usability and originality over decoration.
